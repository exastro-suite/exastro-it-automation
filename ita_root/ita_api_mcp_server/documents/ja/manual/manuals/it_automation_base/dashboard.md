# メインメニュー(Dashboard)のWidget設定

メインメニューにはWidgetが表示され、内容や配置をユーザーごとにカスタマイズできます。カスタマイズしたDashboard構成はユーザー単位でシステムに保存されるため、別環境からログインしても同じ設定が利用できます。

## Widget一覧

| No | Widget名 | 説明 | デフォルト |
|---|---|---|---|
| 1 | メニューグループ | 各メニューグループのパネルを表示（インストールしたドライバーのみ表示）。削除不可。 | 表示 |
| 2 | Movement | 各オーケストレーションのMovement件数を円グラフ表示。 | 表示 |
| 3 | 作業状況 | Conductorの作業状況ステータス別件数を円グラフ表示。 | 表示 |
| 4 | 作業結果 | Conductorの作業結果ステータス別件数を円グラフ表示。 | 表示 |
| 5 | 作業履歴 | Conductorの作業履歴を日別に棒グラフ表示。 | 表示 |
| 6 | メニューセット | メインメニューとは別のメニューグループセットを作成。 | 非表示 |
| 7 | リンク | リンクのリストを作成。 | 非表示 |
| 8 | 予約作業確認 | ステータス「未実行（予約）」のConductor一覧（インスタンスID、Conductor名、オペレーション名、予約日時、残り時間）を表示。 | 非表示 |
| 9 | 画像 | 画像を貼り付け。 | 非表示 |

## Dashboard編集

編集モードでは、Widget追加・編集・削除、編集反映（変更を確定）、リセット（初期状態に戻す）、編集取消（変更前の状態に戻す）が可能です。既存Widgetの上下に「Blank」（空行）を追加・削除できます。「メニューグループ」Widgetのパネルはドラッグ＆ドロップで「メニューセット」Widgetに移動できます。

## Widget共通設定

名称、横/縦結合数、Widget表示（表示する/しない）、タイトルバー（表示する/しない）、枠・背景（表示する/しない）。

## Widget固有設定

| Widget | 設定項目 |
|---|---|
| メニューグループ／メニューセット | 1行項目数、表示形式（アイコン／リスト）、メニューグループ名の表示/非表示、ページ移動方法（同じタブ／別タブ／別ウィンドウ） |
| Movement登録数／Conductor作業状況／Conductor作業結果 | ページ移動方法 |
| Conductor作業履歴／Conductor予約作業確認 | 期間、ページ移動方法 |
| リンクリスト | 1行項目数、ページ移動方法、項目（名称・リンクURLを追加・順序変更・削除可能） |
| 画像 | 画像URL、リンクURL、ページ移動方法 |
