# Excel一括エクスポート・インポート機能

Excel一括エクスポート・インポートは、各メニューにあるダウンロード可能なExcelファイルをzipにまとめて一括でエクスポート・インポートする機能です。エクスポート可能なメニューは、ロール・メニュー紐付管理で「紐付け」が「閲覧のみ」または「メンテナンス可」かつ編集用Excelファイルのあるメニューです。インポート可能なメニューは「メンテナンス可」かつ編集用Excelファイルのあるメニューのみです。

## メニュー構成

| メニュー・画面 | 説明 |
|---|---|
| Excel一括エクスポート | 各メニューのダウンロード可能ファイルをzipにまとめエクスポート。 |
| Excel一括インポート | ダウンロード可能ファイルをまとめたzipをインポート。 |
| Excel一括エクスポート・インポート管理 | 実行したエクスポート・インポートの状況を管理。 |

## Excel一括エクスポート

エクスポートする廃止情報（全レコード／廃止を除く／廃止のみ）とメニューを選択し、《エクスポート》を実行します。実行№が表示され、管理メニューでステータスを確認します。

エクスポートファイルの構成: `ITA_FILES_YYYYMMDDhhmmss.zip` の中に `MENU_LIST.txt`（エクスポートしたメニューREST名とファイル名の一覧）と、メニューグループごとのフォルダ（フォルダ名「メニューグループID_メニューグループ名」、200文字超は前方200文字のみ出力）があり、各フォルダ配下に編集用Excelファイル（xlsx）が配置されます。

## Excel一括インポート

エクスポートしたzip内の`MENU_LIST.txt`を編集することでインポート対象のファイルリストを調整できます（`#`始まりはコメント、フォーマットは`メニューREST名:ファイル名`）。インポートに必要なファイル: `MENU_LIST.txt`とインポート対象ファイル一式（メニューグループフォルダ配下に配置）。

zipをアップロードするとメニュー一覧が表示され、インポートしたいメニューにチェックを入れて《インポート》を実行します（チェックを外すとインポート対象外）。以下に該当する場合、対象メニューのチェックボックスが非活性となりエラーになります。

1. `MENU_LIST.txt`に同じメニューREST名を2つ以上指定している。
2. `MENU_LIST.txt`に別メニューで同じファイル名を2つ以上指定している。
3. `MENU_LIST.txt`のフォーマットに沿わない記述がある。
4. `MENU_LIST.txt`に存在しないメニューREST名が記載されている。
5. `MENU_LIST.txt`でzip内に存在しないファイルを指定している。
6. 別フォルダに同名ファイルが2つ以上ある。
7. `MENU_LIST.txt`が含まれていない。
8. メニューグループフォルダ名が「メニューグループID_メニューグループ名」の形式でない。
9. 対象メニューに対しログインユーザが「メンテナンス可」の権限を持たない。

## Excel一括エクスポート・インポート管理

エクスポート・インポートの実行状況を管理します。項目: 実行No.（自動採番）、ステータス（未実行→実行中→完了、エラー時は完了(異常)）、処理種別（エクスポート／インポート）、廃止情報（全レコード／廃止を除く／廃止のみ）、実行ユーザ、ファイル名（完了後にダウンロード可）、言語（ログインユーザの言語でエクスポートされる）、結果（インポート結果を記載したテキストファイル）。

結果ファイルはインポートしたファイル単位で「登録／更新／廃止／復活／エラー」の件数と、エラー内容（例: `movement_name: ['必須項目です。:(12行目)']`）が出力されます。編集用Excelファイルとして不正な場合は「このメニューの編集用Excelファイルではありません。」と出力されます。
