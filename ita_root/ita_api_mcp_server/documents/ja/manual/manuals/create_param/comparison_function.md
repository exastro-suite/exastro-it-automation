# パラメータシート比較機能の設定と利用方法

比較機能とは、パラメータシート作成機能で作成したパラメータシート（ホスト/オペレーションあり）を比較し、差分を出力する機能です。

## 基準日時について

基準日時とは、対象オペレーションが過去に一度でも実行されていれば「最終実行日時」、一度も実行されていなければ「実施予定日時」を指します。比較実行時に基準日時を指定すると、その時点の最新データで比較します（未入力時は最新の基準日時のデータを使用）。

## 比較機能の実行要件

- パラメータシート（ホスト/オペレーションあり）が作成されている。
- 比較設定で比較対象パラメータシート同士の紐づけがされている。
- 比較詳細設定で比較対象項目同士の紐づけがされている（比較設定の詳細設定フラグが「True」の場合のみ必要。項目数・項目名が完全一致する場合はFalseで詳細設定不要）。

## 比較対象項目とその組み合わせ

比較可能な項目種別: 文字列(単一行/複数行)、整数、小数、日時、日付、プルダウン選択（参照先が廃止されている場合は「ID変換失敗(X)」表記）、ファイルアップロード（ファイル名・内容で比較）、リンク、パラメータシート参照（参照先が廃止されている場合は「ID変換失敗(X)」表記）。

異なる種別同士でも比較可能ですが、ファイルアップロード項目と他の項目種別を比較する場合、ファイル名または内容のどちらかで差分があれば「差分あり」と判定されます（ファイルアップロード以外の項目はファイル内容を空扱いとして比較）。

## メニュー構成

| No | メニュー・画面 | 説明 |
|---|---|---|
| 1 | 比較設定 | 比較実行する設定名を作成し、比較対象のパラメータシートを紐付ける。詳細設定フラグをTrueにすると比較詳細設定が可能になる。 |
| 2 | 比較詳細設定 | 比較するパラメータシートの項目単位での紐付設定を行う。 |
| 3 | 比較実行 | 比較設定・比較詳細設定に基づき比較を実施する。 |

## 作業フロー

1. パラメータシート（ホスト/オペレーションあり）を作成し、データを登録する。
2. 比較設定を作成（対象パラメータシート1・2の紐付、必要なら詳細設定フラグをTrue）。
3. 必要に応じて比較詳細設定で項目同士を紐付ける。
4. 比較実行で比較設定を選択し、比較を実行する。

## 比較設定

比較実行時に使う設定情報（対象パラメータシートの紐付）を登録・更新します。

| 項目 | 説明 | 入力必須 | 制約事項 |
|---|---|---|---|
| 比較名称 | 任意の名称 | 〇 | 最大255バイト |
| 対象パラメータシート1・2 | 比較対象のパラメータシート | 〇 | - |
| 詳細設定フラグ | False＝比較詳細設定不要（両パラメータシートの項目数・項目名が完全一致している必要あり）、True＝比較詳細設定が必要 | - | - |
| 備考 | 自由記述 | - | - |

## 比較詳細設定

比較対象の項目名とパラメータシートの項目同士の紐付を設定します（比較設定で詳細設定フラグがTrueのものが選択対象）。

| 項目 | 説明 | 入力必須 | 制約事項 |
|---|---|---|---|
| 比較名称 | 詳細設定フラグTrueの比較設定から選択 | 〇 | - |
| 比較項目名称 | 比較結果に出力される項目名 | 〇 | 最大255バイト |
| 対象項目1・2 | 比較設定の対象パラメータシート1・2内の項目から選択 | 〇 | - |
| 表示順 | 比較結果で昇順表示される順序 | 〇 | 0〜2147483647 |
| 備考 | 自由記述 | - | - |

## 比較実行

比較設定・比較詳細設定の定義に基づきパラメータシートの比較を実行します。バンドル利用時のパラメータシートは、同一項目名、または比較詳細設定で紐づけた項目の同一代入順序同士で比較されます。

比較実行のパラメータ: 比較設定選択（必須）、基準日時1・2（未入力時は最新の基準日時が適用）、ホスト選択（デフォルトは絞り込みなし、全ホストの結果を出力）。

比較結果は、対象ホスト一覧（ホスト名と差分有無「✓」）とホスト別の比較結果詳細（項目名、差分有無、比較対象パラメータシート1・2の値、備考）で構成されます。ファイルアップロード項目はテキストベースのファイルであれば内容差分を閲覧できますが、バイナリファイルの内容差分は閲覧できません。バンドル利用時の比較項目は「項目名[代入順序]」形式で表示され、項番・ホスト名・オペレーション名・基準日時は比較結果に表示されません。
