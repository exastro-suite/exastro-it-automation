# ITAメニュー共通操作の仕様

ITAが提供する各メニュー画面は基本的に同じ構成要素（メニュー名、メニュー、サブメニュー、ワークスペース情報、ログイン情報）で構成されます。

## 一覧タブの主な機能

### 登録・編集

登録・編集内容は各メニューによって異なります。ボタンの挙動: 「追加」＝新規登録レコードの追加（複数件同時登録用）、「複製」＝チェックしたレコードの複製（**パスワード項目は複製されない**）、「削除」＝チェックしたレコードの削除、「廃止」＝チェックしたレコードの廃止フラグをTrueにする（編集反映後に廃止となる）。プルダウン入力は部分一致検索（大文字小文字・全角半角を補正）で絞り込めます。

**ファイルアップロード項目**: 「+」でファイル選択アップロード、テキストファイルはエディタで作成・編集・ダウンロード可能（編集内容は「更新」でファイルに反映されるがレコードには未保存、編集確認→編集反映で確定）、削除も編集反映まで確定しません。アップロード禁止拡張子は管理コンソールのシステム設定で識別ID「FORBIDDEN_UPLOAD」により設定します（許可拡張子を増やすとセキュリティホールの可能性があるため注意）。プレビュー可能な拡張子: 画像（gif, jpe, jpg, jpeg, png, svg, webp, bmp, ico, avif）、テキスト（txt, yaml, yml, json, hc, hcl, tf, sentinel, py, j2, css, html, htm, js）、または拡張子なしの場合。

### 表示フィルタ

- **廃止カラム**: 「廃止含まず」（初期値）／「全レコード」／「廃止のみ」のいずれかの選択が必須です。
- **検索条件**: 複数項目を指定するとAND条件、同一項目に「あいまい検索」と「プルダウン検索」を組み合わせるとOR条件になります。ファイルアップロード項目の検索対象はファイル名です。整数・小数・年月日・年月日時の項目は「以上」「以下」「範囲指定」で検索できます。
- **オートフィルタ**: チェックすると条件選択毎に自動で一覧が更新されます。デフォルトのチェック有無は管理コンソール「メニュー管理」の「オートフィルタチェック」で設定します。
- **ダウンロード**: Excel形式、JSON形式（ファイルアップロード項目はbase64でダウンロード）、JSON形式（ファイルなし、ファイルデータを含めない）が選択できます。表示フィルタからダウンロードしたExcel/JSONファイルは全件ダウンロード・ファイル一括登録機能でも使用できます。

### テーブル設定

サーバー側に保持され、別端末・別ブラウザからアクセスしても同じ設定が適用されます。「共通設定」は全メニューのサブメニュー共通部分に適用、「個別設定」は設定したメニューのみに適用（個別設定で「共通設定」を選んだ項目は共通設定の値が使われる）。設定項目: 項目表示方向（縦／横）、フィルタ表示位置（内側／外側。項目表示方向が横の場合は外側固定）、項目メニュー表示（省略／表示。省略時は各レコードの操作メニューアイコンから表示可能）、項目表示・非表示と左右固定（個別設定のみ）。

## 変更履歴タブ

各メニューの主キー単位で変更履歴（変更実施日時の新しい順、前回との変更箇所はオレンジ色太字）を表示できます。

**プルダウン選択（参照項目）を含む場合の注意**: プルダウン選択の参照元（例: データシートの値）を変更すると、参照側（例: パラメータシートの表示値）の値も自動的に変わります。ただし「変更履歴」には、参照側のレコード自体を編集（登録/更新/廃止/復活）した**その時点の参照先の値**が記録され、その後に参照先だけが変更されても参照側の履歴は更新されません。つまり履歴上の値は「編集操作をした瞬間の参照値のスナップショット」であり、参照先の最新値と一致しない場合があります。

## 全件ダウンロード・ファイル一括登録

各メニューの登録情報をExcel形式またはJSON形式で一括ダウンロード・一括登録できます。

- **Excel**: 更新/廃止/復活を行う場合は「全件ダウンロード(Excel)」、新規登録の場合は「新規登録用ダウンロード(Excel)」を使用します。「変更履歴全件ダウンロード(Excel)」からダウンロードしたファイルは一括登録に使用できません。ファイル内の「実行処理種別」が未選択または不正な場合、登録は実行されません。
- **JSON**: 更新/廃止/復活・新規登録のいずれも「全件ダウンロード(JSON)」を使用します。

ダウンロードしたファイルを編集し、対応する「ファイル一括登録」から対象ファイルを選択してアップロードします（編集内容は各メニューのマニュアルに従う）。
