# メニューエクスポート・インポート機能

メニューエクスポート・インポートは、移行したいITAのメニューを選択し、メニュー単位でデータを上書き移行する機能です。データを別環境に移す場合、整合性を保つため基本的に全メニューを対象に移行する必要があります。

## モード

| モード | 説明 |
|---|---|
| 環境移行 | 指定メニューの全データをエクスポートし、インポート時に既存データを全て削除して上書き（置き換え）します。 |
| 時刻指定 | 指定時刻以降のデータのみエクスポートし、インポート先データと一意項目（ID、No等）が重複した場合はエクスポートデータが優先してインポートされます。 |

廃止情報: 「廃止を含む」（廃止データも含め全件）／「廃止を除く」。履歴情報: 「履歴あり」／「履歴なし」（いずれも重複時はエクスポートデータが優先）。

## 使用例

**パターン①環境の複製**: 環境移行モードでワークスペースAの全データをエクスポートし、ワークスペースBにインポートします。移行後にAへ再度データを移行すると不整合が生じる可能性があるため非推奨、双方向の移行も非推奨です。

**パターン②データ投入用と実行用ワークスペースの分離**: 環境移行モードで初回移行後、ワークスペースAでの更新ごとに時刻指定モードで差分をワークスペースBへ移行します。ワークスペースBで作業実行中にデータ移行する場合は、実行中データへの影響を避けるため時刻指定モードで差分のみを移行してください。ワークスペースBでのデータ登録・更新（作業実行以外）は不整合の可能性があるため非推奨、双方向移行も非推奨です。

## リソース制限について

エクスポート・インポート処理中のリソースはリソースプランで制御されます。Backyard処理は入出力を分割して処理し、リソースプランの値`ita.organization.menu_export_import.buffer_size`を上げると処理時間は短縮されますが使用リソース量が増加します。

## 環境差分（バージョン・ドライバ）による利用可否

エクスポートしたKYMファイルは、以下をすべて満たす場合に後方互換性があります: ①2.5.0以降のITAでエクスポート、②インポート先のITAバージョンがエクスポート元より新しい、③エクスポート元にインストールされているドライバがインポート先にもインストールされている。

| ケース | バージョン差分 | ドライバ差分 | インポート可否 |
|---|---|---|---|
| A | なし | なし | 〇 |
| B | なし | あり（インポート先がドライバ多い） | 〇 |
| C | あり（インポート先が新しい） | なし | 〇 |
| D | あり（インポート先が新しい） | あり（インポート先がドライバ多い） | 〇 |
| E | なし | あり（インポート先がドライバ少ない） | △（ドライバのインストール/アンインストール機能でドライバ構成を揃えればケースA/B相当にして可） |
| F | あり（インポート先が新しい） | あり（インポート先がドライバ少ない） | △（同上、ケースC/D相当にして可） |
| G | あり（インポート元が新しい） | なし | × |
| H・I | あり（インポート元が新しい） | あり | × |

エクスポート元のバージョンがインポート先より新しい場合（G/H/I）はインポート不可です。

## メニュー構成

| メニュー・画面 | 説明 |
|---|---|
| メニューエクスポート | メニューのデータをエクスポート。 |
| メニューインポート | メニューのデータをインポート。 |
| メニューエクスポート・インポート管理 | 実行したエクスポート・インポートの状況を管理。 |

## メニューエクスポート

エクスポート対象外のメニュー: エクスポート・インポート関連メニュー（メニューエクスポート、メニューインポート、メニューエクスポート・インポート管理、Excel一括エクスポート、Excel一括インポート、Excel一括エクスポート・インポート管理）、Conductor関連の作業実行・履行状態系メニュー（Conductor編集/作業実行、Conductor作業履歴、Conductor作業確認、Conductorインスタンス一覧、ConductorNodeインスタンス一覧）、パラメータシート作成関連（パラメータシート定義・作成、パラメータシート作成履歴、選択1、選択2）、比較実行、各ドライバ（Ansible-Legacy/Pioneer/LegacyRole、Terraform-Cloud/EP、Terraform-CLI）の作業対象ホスト・代入値管理・作業実行・作業状態確認・作業管理・作業確認・連携先Terraform管理。

モードと廃止情報・履歴を選択してメニューを選択し《エクスポート》を実行、確認ポップアップで《エクスポート開始》を押すとエクスポート・インポート管理画面に遷移してステータスを確認できます。

初回の環境移行や新規パラメータシート作成でメニューを作成した場合、以下のメニューをエクスポート対象に含める必要があります（含めない場合インポート時に完了（異常）になります）: メニュー管理、メニュー-テーブル紐付管理、メニュー-カラム紐付管理、ロール-メニュー紐付管理。

## メニューインポート

エクスポートしたファイルをアップロードし、インポート対象メニューにチェックを入れて《インポート》を実行、確認ポップアップで《インポート開始》を押すとエクスポート・インポート管理画面でステータスを確認できます。インポートのステータスが「実行中」の間にすぐ他の操作（画面更新や他メニューへの遷移）を行うと、データ入れ替えのタイミングによりシステムエラーになる可能性があるため、時間を置いてから操作してください。

## メニューエクスポート・インポート管理

項目: 実行No.（自動採番）、ステータス（未実行→実行中→完了、エラー時は完了(異常)。インポート時に完了(異常)となった場合は自動でロールバックしインポート前の状態に戻す）、処理種別（エクスポート／インポート）、モード（環境移行／時刻指定）、廃止情報（廃止を含む／廃止を除く）、履歴情報（履歴あり／履歴なし）、指定時刻（モードが時刻指定の場合のみ表示）、ファイル名（完了後にダウンロード可）、実行ユーザ、言語（インポート実行時のログインユーザの言語、自動登録で編集不可）、実行ログ（完了(異常)時にログファイルのリンクを表示。例: `KYMファイル内に該当ファイルがありません。(T_COMN_MENU_TABLE_LINK_DATA)`）。
