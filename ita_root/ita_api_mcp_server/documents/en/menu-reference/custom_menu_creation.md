# Reference for creating custom menus (custom_menu_creation.md)

In the Exastro IT Automation (ITA) management console, in addition to the initial menus, a "custom menu" can be created so that a using department can manage its own information.
A custom menu is realized by compressing the HTML/JavaScript/CSS etc. to be displayed on the menu into a ZIP as "custom menu material" and registering it.
This reference summarizes the procedure for creating a custom menu, the specification of the material ZIP, the available JavaScript libraries, and how to use ITA's standard JavaScript/CSS (common.js, ui.js, table.js, dialog.js).

## How to register a custom menu (important)
- A custom menu is created by **registering a record in the management console's "Menu Management" (menu_list) menu**. The `menu_list` menu is a normal menu that is writable from MCP, and **it can be registered using the MCP `maintenance-all` tool** (manual operation on the screen is not required).
- **Do not use the `create-menu` tool**. `create-menu` is a dedicated tool for newly creating parameter sheets/data sheets (menus that have item definitions), and it is not used for registering a custom menu.
- Registration flow:
    1. Compress the full set of materials, including `main.html`, into a ZIP (follow the "Specification of custom menu material (ZIP)" below). Pass the ZIP generated by the agent by issuing a `file_id` with `create-text-file` or similar.
    2. Register a record for the `menu_list` menu using `maintenance-all`, and link the `file_id` above to the "Custom menu material" item.
    3. Beforehand, use `list-menu-info` to check whether `menu_list` is writable (`row_insert_flag`/`row_update_flag`) and the type of each item.

## Procedure for using a custom menu
1. In the **Menu Management** (menu_list) menu, register the "custom menu material" (ZIP) to create a new menu.
2. In the **Role-Menu Association Management** menu, grant "Maintainable" or "View only" permission to the created menu for the target role.
   - Note: A menu screen that is not associated with a role is not displayed in the menu group.
3. Display the registered menu.

## Specification of custom menu material (ZIP)
- This material is only used when a menu has been registered directly via Menu Management. Even if registered for an existing menu or a menu created via the parameter sheet creation feature, it will not be used.
- Compress the HTML, JavaScript, CSS, etc. to be displayed on the menu into a ZIP and register it.
- **The HTML to be displayed as the main content must be a file named "main.html"** — this name is fixed.
- The names of other files used within "main.html" are arbitrary.
- **All files inside the ZIP must be placed directly at the root of the folder** (subfolders are not allowed).
- If a menu without registered "custom menu material" is displayed, nothing is shown.

### common.js
Gathers various basic functions into the `fn` variable. Required when using other ITA JavaScript.

```html
<script src="/_/ita/js/common.js"></script>
```

#### fn.fetch
Sends a request to the ITA API.

```javascript
const result = await fn.fetch( URL, TOKEN, METHOD, BODY );
```
- **URL**: The API endpoint. Omit the leading `/api/{organization_id}/workspaces/{workspace_id}/ita`.
- **TOKEN**: Normally specify `null`. When used inside a Worker etc., obtain and pass a Token separately.
- **METHOD**: A method such as `POST` or `GET`. Defaults to `GET` when omitted.
- **BODY**: Body data for a POST. Can be omitted.

Usage example (get the operation list):
```javascript
async function operationList(){
    const result = await fn.fetch('/menu/operation_list/filter/', null, 'POST', {"discard": {"NORMAL": "0"}});
    console.log( result );
}
```

#### fn.xhr
Registers data. Registration is also possible with fn.fetch, but fn.xhr is limited to data registration and shows registration progress.

```javascript
const result = await fn.xhr( URL, FORMDATA );
```
- **URL**: The API endpoint. `/menu/{menu_name_rest}/maintenance/all/`.
- **FORMDATA**: Convert the data to be registered into form data and pass it.

Usage example (register one operation):
```javascript
window.addEventListener('DOMContentLoaded', () => {
    registerOperation();
});

async function registerOperation(){
    // Form data
    const formData = new FormData();

    // Data to register
    const regsterData = [
        {
            parameter: {
                discard: '0',
                operation_name: 'Operation name',
                scheduled_date_for_execution: '2024/12/31 00:00:00'
            },
            file: {},
            type: 'Register'
        }
    ];

    // Add the parameters to the form data (convert regsterData to a string)
    formData.append('json_parameters', JSON.stringify( regsterData ) );

    // Register
    const result = await fn.xhr('/menu/operation_list/maintenance/all/', formData );

    console.log( result );
}
```

### ui.js
Generates ITA's basic screen elements (tabs, containers, etc.).

```html
<script defer src="/_/ita/js/ui.js"></script>
```

Usage example (create a screen with three tabs):
```javascript
window.addEventListener('DOMContentLoaded', () => {
    // Target
    const $content = $('#content');

    // ui.js
    const ui = new CommonUi();

    // Menu information
    ui.info = {
        menu_info: {
            menu_name: 'Tab menu sample',
            menu_info: 'This is a tab menu sample.'
        }
    };

    // HTML inside the tabs
    ui.tab1 = function(){ return 'Tab1 Contents'};
    ui.tab2 = function(){ return 'Tab2 Contents'};

    // Tab definitions
    // The function set above is called by name. It also becomes the tab's ID.
    // title is displayed on the tab.
    // Specifying type: 'blank' creates an empty tab.
    const tabs = [
      { name: 'tab1', title: 'Tab 1'},
      { name: 'tab2', title: 'Tab 2'},
      { name: 'tab3', title: 'Tab 3', type: 'blank'}
    ];

    // Create the tab HTML
    const tabHtml = ui.contentTab( tabs );

    // Menu title / description area
    const menuHtml = ui.commonContainer( ui.info.menu_info.menu_name, ui.info.menu_info.menu_info, tabHtml );

    // Set the tabContent class on the target and set the HTML
    $content.addClass('tabContent').html( menuHtml );

    // Tab 3 was created as blank, so set its HTML separately
    $('#tab3').find('.sectionBody').html('Tab3 Contents');

    // Set the tab event. Specify the name of the tab that is open first as the argument.
    ui.contentTabEvent('#tab1');

    // Set the menu detail button event
    ui.setCommonEvents();
});
```

### table.js
Can display/edit the specified parameter sheet as a table.

```html
<script defer src="/_/ita/js/table.js"></script>
```

```javascript
const table = new DataTable( ID, MODE, INFO, PARAMS );
const $table = table.setup();
```
- **ID**: Specify a unique ID.
- **MODE**: `view` (basic) or `history` (history display).
- **INFO**: Menu information. Pass the information obtained via `/menu/{menuNameRest}/info/`.
- **PARAMS**: Specify the required parameters.

Usage example (display the operation list):
```javascript
window.addEventListener('DOMContentLoaded', async () => {
    // Target
    const $content = $('#content');

    // Operation list menu name (REST)
    const menuNanmeRest = 'operation_list';

    // Get the menu information
    const info = await fn.fetch(`/menu/${menuNanmeRest}/info/`);

    // Get the required parameters
    const params = fn.getCommonParams();
    params.menuNameRest = menuNanmeRest;

    // Create the table
    // table.setup() returns a jQuery object for the table.
    const table = new DataTable('operationList', 'view', info, params );
    $content.html( table.setup() );
});
```

### dialog.js
Displays a dialog.

```html
<script defer src="/_/ita/js/dialog.js"></script>
<link rel="stylesheet" href="/_/ita/css/dialog.css">
```

```javascript
const dialog = new Dialog( CONFIG, FUNCTIONS );
dialog.open( CONTENTS );
```
- **CONFIG**: Dialog configuration information.
- **FUNCTIONS**: Functions called when a dialog button is pressed.
- **CONTENTS**: The dialog body HTML.

Usage example (display "Hello world" and branch processing between OK and Close):
```javascript
window.addEventListener('DOMContentLoaded', async () => {
    const flag = await helloWorld();
    if ( flag ) {
        console.log('OK!');
    } else {
        console.log('CLOSE!!')
    }
});

function helloWorld(){
    return new Promise(function( resolve ){
        // Behavior when a button is pressed
        const functions = {
            // Function called when OK is pressed
            ok: function(){
                this.close();
                resolve( true );
            },
            // Function called when Close is pressed
            close: function(){
                this.close();
                resolve( false );
            }
        };
        // Dialog display definition
        const config = {
            // Modal position: top or center
            position: 'center',
            // Header information
            header: {
                title: 'Dialog test'
            },
            // Width
            width: '640px',
            // Footer information
            footer: {
                // Button information
                button: {
                    // Linked by the same key name as functions.
                    // text: displayed text.
                    // action: the button's role (positive, restore, duplicat, warning, danger, history, normal, negative) - this only changes the color.
                    // style: specify the style.
                    ok: { text: 'OK', action: 'default', style: 'width:160px;'},
                    close: { text: 'Close', action: 'normal'}
                }
            }
        };
        const dialog = new Dialog( config, functions );
        dialog.open('<div style="padding:24px;text-align:center;font-size:24px;">Hello World</div>');
    });
}
```

## Minimal sample of main.html
An example of writing HTML/JS/CSS together in `main.html` (equivalent to Sample ①). Place it directly under the ZIP root as `main.html`.

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Custom menu sample</title>
    <script src="/_/ita/lib/jquery/jquery.js"></script>
    <link rel="stylesheet" href="/_/ita/css/common.css">
</head>
<body>
    <div id="content">
        <button id="helloButton" type="button">Hello</button>
    </div>
    <script>
        $('#helloButton').on('click', function(){
            alert('Hello');
        });
    </script>
</body>
</html>
```
