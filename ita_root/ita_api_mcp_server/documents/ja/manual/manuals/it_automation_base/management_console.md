# 管理コンソールの設定と独自メニュー開発

管理コンソールでは、初期メニュー以外に利用部門が独自の情報をITAのデータベース上で管理するための個別メニューを作成できます（個別メニューの登録／変更／削除は製品サポートに問い合わせが必要）。

## メニュー構成

管理コンソール: メインメニュー、システム設定、メニューグループ管理、メニュー管理、ロール・メニュー紐付管理、オペレーション削除管理、ファイル削除管理。

## システム設定

ITAシステム導入・運用時に設定すべき各種情報を更新します。項目: 識別ID（システム設定識別用、**変更禁止**。変更するとITAの動作が保証されない）、項目名、設定値、備考。

## メニューグループ管理

メニュー（子）が属する親のメニューグループを登録／更新／廃止します。

| 項目 | 説明 |
|---|---|
| メニューグループID | メニューグループのID |
| 親メニューグループ | 親のメニューグループ |
| メニューグループ名(ja/en) | 表示名。**一意である必要があり、重複登録不可** |
| パネル画像 | メニューグループのパネル画像。**PNGファイルのみ**使用可 |
| パラメータシート作成利用フラグ | パラメータシート作成機能の「対象メニューグループ」として利用可能かのフラグ |
| 表示順序 | メインメニューでの表示順序（昇順表示。同じ場合はメニューグループIDの昇順） |
| 備考 | 自由記述（任意） |

データ更新系操作のためシステム管理者でログインが必要です。

## メニュー管理

コンテンツ機能（メニュー）を登録／更新／廃止します。

| 項目 | 説明 |
|---|---|
| メニューID | メニューのID |
| メニューグループ | 親となるメニューグループ |
| メニュー名(ja/en/rest) | 表示名・REST名。**メニュー名称は一意である必要がある** |
| メニューグループ内表示順序 | サブメニューでの表示順序 |
| オートフィルタチェック | メニュー表示時にオートフィルタのチェックを入れるか |
| 初回フィルタ | メニュー表示時にフィルタをクリックした状態で表示するか |
| 独自メニュー用素材 | 独自メニュー表示用のZIPファイル（後述） |
| Web表示最大行数 | 「一覧」に表示する最大行数 |
| Web表示前確認行数 | 「一覧」出力前に確認ダイアログを表示する最大行数 |
| Excel出力最大行数 | Excel出力の最大行数（0〜1048576） |
| ソートキー | 一覧の並び順（JSON形式、例: `{"ASC":"display_order"}`。項目名にASC/DESC、値にキー列名） |

各メニュー項目一覧（または全履歴数）がExcel出力最大行数を超える場合、「全件ダウンロード・ファイル一括登録」タブのExcelダウンロードは中止されます（JSON形式は可能）。画面下部の変更履歴全件ダウンロードは確認用途のみでアップロード非対応です。

### 独自メニュー用素材について

「メニュー管理」でメニューを直接登録した場合にのみ使用される素材です（既存メニューやパラメータシート作成機能で作成したメニューには適用されません）。表示させたいHTML/JavaScript/CSSをZIPに圧縮して登録し、メイン表示用HTMLはファイル名固定で`main.html`とします（`main.html`内で使うファイル名は任意）。ZIP内のファイルは全てフォルダ直下に配置する必要があります。新規メニューに素材未登録の場合、表示しても何も表示されません。表示するには、素材登録後に「ロール・メニュー紐付管理」で対象メニューに「メンテナンス可」または「閲覧のみ」の権限を付与する必要があります。

## ロール・メニュー紐付管理

各メニューとロールの対応付けを登録／更新／廃止します。ロールに紐付かないメニュー画面はメニューグループに表示されません。項目: UUID、ロール、メニュー、紐付（「メンテナンス可」または「閲覧のみ」）、備考（任意）。

## オペレーション削除管理・ファイル削除管理

詳細はメンテナンスの「オペレーション自動削除」「ファイル自動削除」を参照してください。

## 独自メニュー開発（JavaScriptライブラリ・API）

ITAが使用する主なJavaScriptライブラリ: jQuery 3.5.1（MIT）、select2 4.0.13（MIT、jQuery併用）、Ace v1.5.0（BSD、json/python/terraform/text/yaml対応エディタ）、ExcelJS 4.3.0（MIT）、diff2html v2.11.3（MIT）。これらはITAが提供するパス（例: `/_/ita/lib/jquery/jquery.js`）から読み込めます。

独自メニューでITA標準の画面を再現する場合、ITA提供のJS/CSSが利用できます（別途jQueryと言語ファイルの読み込みが必要）。

- **common.js**（必須基盤）: `fn.fetch(URL, TOKEN, METHOD, BODY)`でITA APIにリクエスト（URLは`/api/{organization_id}/workspaces/{workspace_id}/ita`を省略した形、TOKENは通常null、METHODは省略時GET）。`fn.xhr(URL, FORMDATA)`はデータ登録専用で進捗表示付き（URLは`/menu/{menu_name_rest}/maintenance/all/`形式、FORMDATAはFormDataオブジェクト）。
- **common.css**: ITAの基本画面スタイル（ITA JS使用時は読み込み必須）。
- **ui.js**: `new CommonUi()`でタブ画面等の基本UIを生成（`ui.info.menu_info`にメニュー名・説明、`ui.contentTab(tabs)`でタブHTML生成、`type: 'blank'`で空タブ、`ui.contentTabEvent('#tab1')`でタブイベント設定）。
- **table.js**: `new DataTable(ID, MODE, INFO, PARAMS)`で指定パラメータシートのテーブル表示・編集を生成（MODEは`view`基本表示または`history`履歴表示、INFOは`/menu/{menuNameRest}/info/`の取得結果、PARAMSは`fn.getCommonParams()`に`menuNameRest`を追加したもの）。
- **dialog.js**: `new Dialog(CONFIG, FUNCTIONS)`でダイアログを生成し`dialog.open(CONTENTS)`で表示（CONFIGでpositon/header/width/footerのボタン構成、FUNCTIONSでボタン押下時の処理を定義。ボタンの`action`は表示色のみに影響: positive/restore/duplicate/warning/danger/history/normal/negative）。
