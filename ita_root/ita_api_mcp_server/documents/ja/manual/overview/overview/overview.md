# Exastro IT Automation概要

Exastro IT Automation（ITA）は、システム設定をデジタル化して一元管理するオープンソースフレームワークです。機器情報、設定値、作業履歴などのシステム構成情報を管理し、Excelデータとして出力できます。また各機器のシステム構築や運用設定をワークフローとして管理・実行する機能を備え、様々なPF構築ツールと連携できます。

## 特徴

- **マルチインタフェースとRBAC**: Web、Spreadsheet、REST APIの3種類のI/Fから操作可能。どのI/Fからの操作でも「誰が・いつ・何をしたか」を記録。RBAC（Role-based access control）により開発者・作業者・運用者などの役割を定義し、役割ごとに参照のみ/更新/実行の権限を制御できる。
- **パラメータのグルーピング／履歴管理**: システムのパラメータ情報をグルーピング・履歴管理できる。
- **IaCを解析して変数を刈り取る**: Infrastructure as Code（IaC）アップロード時に誤りを解析し、記述から変数名を刈り取って管理。変数名は選択式で利用するためヒューマンエラーが起きない。
- **IaCをモジュール管理して再利用性を高める**: IaC（Playbook等）を一発モノで終わらせず、モジュール化して作業時に組み立て・再利用できる。
- **複数の自動化ソフトウェアを繋げて実行**: 複数の自動化ソフトウェアを繋げて一本の作業フローを定義でき、動作に必要な投入データを自動生成する（例：Ansibleの場合、必要なPlaybookを集めて繋げ、ノード毎にパラメータからhost_varsを作成）。
- **自動化を止めない最後の切り札Pioneerモード**: Ansibleのどのモジュールでも自動化できない場合の手動作業を避けるため、ITA専用のAnsibleモジュールでssh/telnetいずれかで対話的に自動化を継続できる。
- **実行状況をリアルタイムで監視**: 手動作業と同等にリアルタイムで実行状況を把握でき、実行結果（作業エビデンス）を必要な時にダウンロードできる。

## 機能

- **管理コンソール機能**: 利用ユーザーの登録／更新／削除、操作メニューの権限制御、各種データのインポート／エクスポートを行う。
- **構築資材管理機能**: 自動化ソフトウェア（OSS）で利用するIaCを管理する。バックエンドでGitと連携し、フロントエンドで払出/払戻のステータス管理を提供する。
- **基本コンソール機能**: 機器情報（デバイスリスト）の登録・管理、Conductor（ジョブフロー）の作成・管理・実行など、作業で共通的に必要な機能を提供する。
- **パラメータ／ホストグループ機能**: ホストごと・ホストグループごとのパラメータを一元管理・履歴管理する。管理対象のパラメータは自由に定義可能で、IaC（Playbook等）の変数に紐付けられる。
- **各自動化ソフトウェアに対応したドライバー群**: 複数の自動化ソフトウェアに対応し、それぞれのIaC（Playbook等）を制御するインタフェースを提供する。自動化ソフトウェアの動作はMovement（単位ワーク）に閉じ込められ、Conductor（ジョブフロー）として連結できる。
  - **Movement**: 各機器に対する構築ツールを使った構築・設定作業の単位。
  - **Conductor**: 一連の作業の単位。オペレーション名と関連付けて実行し、Nodeと呼ぶ各種パーツを組み合わせてジョブフローを作成、複数機器に対する一連の構築・設定作業を行う。
  - **オペレーション**: 作業実行単位。作業予定、実行履歴などを管理できる。
