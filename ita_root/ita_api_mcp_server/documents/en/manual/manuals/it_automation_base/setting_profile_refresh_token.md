# Issuing Tokens

A refresh token is required in order to issue the access token needed to call the API. Select "Issue Token" from the logged-in user's icon menu to issue tokens and view the list of issued tokens.

- If two-factor authentication is enabled, you must enter the one-time password from your authenticator app when issuing a token.
- An issued token cannot be displayed again, so you must save it from the issuance result screen.
- The expiration date of an issued token can be checked in the token list.
- Unneeded tokens can be deleted, but **deleting invalidates all tokens** (this is not an individual deletion — it invalidates every token at once).
