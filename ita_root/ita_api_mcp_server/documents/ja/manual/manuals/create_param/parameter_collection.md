# パラメータ集の機能

パラメータ集は、パラメータシート作成機能で作成した複数のパラメータシートを検索条件に基づいて取得、またはデータ登録が行える機能です。

## パラメータモード

| モード | 説明 |
|---|---|
| ホスト | パラメータシートに紐付くホストを1つ選択し、そのホストを基に複数オペレーションのデータを取得する。 |
| オペレーション | パラメータシートに紐付くオペレーションを1つ選択し、そのオペレーションを基に複数ホストのデータを取得する。 |

- 対象パラメータの選択肢は、ロール・メニュー紐付管理で「紐付」項目が「メンテナンス可」または「閲覧のみ」のパラメータシートのみです。ホストグループを利用しているパラメータシートは、代入値自動登録用のパラメータシートを選択します。
- 対象ホストの選択肢は、パラメータシートに登録されているホストのみです。パラメータモードがホストの場合は対象ホスト（ホスト無しを含む）を1つのみ選択、オペレーションの場合は複数ホストとホスト無しの取得対象を選択できます。
- 以下の条件では、パラメータ表示が自動実行されます: ①パラメータモード・対象パラメータ選択済みの状態で対象ホストを選択、②パラメータモード・対象ホスト選択済みの状態で対象パラメータを選択、③パラメータモードがオペレーションで対象パラメータ・対象ホスト選択済みの状態でオペレーションを変更。
- 表示順は対象パラメータの選択順、パラメータモードがオペレーションの場合のホスト表示順は対象ホストの選択順（ホスト無しは最後）です。

## その他の機能

- **プリセット登録**: 検索条件をワークスペース単位でプリセットとして保存・呼び出しできます（更新・名称変更・削除可能）。
- **パラメータシートのメンテナンス**: パラメータ表示実行後に編集できますが、ロール・メニュー紐付管理で「紐付」が「閲覧のみ」のユーザは編集できません。ホストグループを利用するパラメータシートは入力用パラメータシートが表示されます。
- **EXCEL出力**: 1パラメータシート1シートで出力され、シート順は表示結果の表示順に対応します。
