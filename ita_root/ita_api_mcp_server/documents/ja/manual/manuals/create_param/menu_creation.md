# パラメータシート作成機能の設定と利用方法

パラメータシート作成機能は、ITA上で操作可能なメニューを作成する機能です。作成するメニューの種類には「パラメータシート」と「データシート」があり、作成したメニューは他のメニューと同様にWeb・Excel・RestAPIから操作できます。項目数・形式・サイズ・入力制限は自由に設計でき、他メニューのプルダウン参照元としても利用できます。

## パラメータシートとデータシート

- **パラメータシート**: 各ドライバの「代入値自動登録設定」メニューで対象にできるメニューです。パラメータシート（ホスト/オペレーションあり）または（オペレーションあり）を選択して作成し、代入値自動登録設定でIaC変数と紐付けることで、パラメータシートの「パラメータ」項目値をIaC変数に自動代入できます。選択できるパターン: 「ホスト/オペレーションあり」（ホストとオペレーション単位で作成）、「オペレーションあり」（オペレーション単位）、「ホストグループ利用」（ホストグループ機能と連携）、「バンドル利用」（同一項目を繰り返す設定を視認性よく管理）。
- **データシート**: 自由に項目を作成できるメニューで、各ドライバの代入値自動登録設定では利用できません。CMDB（構成管理データベース）としての情報管理や、他メニューのプルダウン選択肢としての利用を想定しています（プルダウン選択肢として使うには対象項目の「必須」と「一意制約」にチェックが必要）。

作成対象と代入値自動登録の利用可否:

| 作成対象 | Ansible driver | Terraform driver |
|---|---|---|
| パラメータシート(ホスト/オペレーションあり) | 〇 選択可能 | × 選択不可 |
| パラメータシート(オペレーションあり) | △ 選択不可（ただしパラメータシート参照項目経由で値を利用可） | 〇 選択可能 |
| データシート | ▲ 選択不可（プルダウン参照項目経由で値を利用可） | ▲ 選択不可（同上） |

## 作成パターンとメニューグループ構成

パラメータシートを選択した場合、3つのメニューグループにメニューが作成されます: **A. 入力用**（メンテナンス可能）、**B. 代入値自動登録用**（閲覧専用）、**C. 参照用**（閲覧専用）。データシートを選択した場合は**A. 入力用**（メンテナンス可能）のみ作成されます。メンテナンス（登録/更新/廃止/復活）ができるのは入力用メニューグループのみです。

作成パターンは合計5つ: ①パラメータシート＋ホストグループ利用＋バンドル利用、②パラメータシート＋ホストグループ利用、③パラメータシート＋バンドル利用、④パラメータシート、⑤データシート。

| パラメータシート作成履歴 | パラメータシート作成の処理状態を確認する。 |
| カラムグループ作成情報 ※非表示 | カラムグループをメンテナンスする。 |
| パラメータシート項目作成情報 ※非表示 | 管理する項目をメンテナンスする。 |
| パラメータシートロール作成情報 ※非表示 | アクセス許可ロールをメンテナンスする。 |
| 一意制約(複数項目)作成情報 ※非表示 | 一意制約(複数項目)をメンテナンスする。 |
| パラメータシート定義-テーブル紐付管理 ※非表示 | 作成したパラメータシートとDBテーブルの紐付を表示（Backyard専用、ユーザー操作対象外）。 |

## 項目・グループの設定（入力方式ごとの設定項目）

1つのパラメータシートに追加できる項目は推奨100個、上限1000個です（多いと表示・動作に影響する可能性）。項目名・カラムグループ名に「/」「\」は使用禁止です。

| 入力方式 | 作成される項目 | 主な設定 |
|---|---|---|
| 文字列(単一行) | 単一行テキストボックス | 最大バイト数（最大65536、半角=文字数、全角=文字数×3+2）、正規表現（例: 半角数値 `^[0-9]*$`）、初期値 |
| 文字列(複数行) | 複数行テキストボックス | 同上 |
| 整数 | 整数チェック付きテキストボックス | 最小値/最大値（-2147483648〜2147483647、未入力時は下限/上限がデフォルト）、初期値 |
| 小数 | 小数チェック付きテキストボックス | 最小値/最大値（-99999999999999〜99999999999999、整数小数合計14桁以下）、桁数（1〜14、未入力時14）、初期値 |
| 日時 | カレンダー選択 | 初期値（`YYYY-MM-DD hh:mm:ss`） |
| 日付 | カレンダー選択 | 初期値（`YYYY-MM-DD`） |
| プルダウン選択 | プルダウン | 選択項目（「メニューグループ：メニュー：項目」形式、選択対象は後述）、参照項目（選択値に応じて他項目を横並び表示、後述）、初期値 |
| パスワード | マスク表示テキストボックス（`*`表示） | 最大バイト数（最大8192） |
| ファイルアップロード | ファイル選択・アップロードボタン付き項目 | ファイル最大バイト数（上限はプランの`ita.organization.common.upload_file_size_limit`） |
| リンク | URLがリンク表示になる項目 | 最大バイト数（最大8192）、初期値 |
| パラメータシート参照 | 作成対象「パラメータシート（オペレーションあり）」メニューの項目値を、オペレーション一致時に参照 | 選択項目（対象は文字列/整数/小数/日時/日付/パスワード/ファイルアップロード/リンクの入力方式のみ） |

各入力方式共通の設定: 必須（チェックボックス）、一意制約項目（チェックボックス）、説明、備考。

**代入値自動登録設定の連携対象項目**: Ansibleドライバは「文字列(単一行/複数行)」「整数」「小数」「パスワード」「リンク」「ファイルアップロード」が連携対象（「日時」「日付」、プルダウン選択で日時/日付を選んだ場合は非対象）。Terraformドライバは「文字列(単一行/複数行)」「整数」「小数」「パスワード」「リンク」が連携対象（「日時」「日付」「ファイルアップロード」、プルダウン選択で日時/日付を選んだ場合は非対象）。

## 「パラメータシート作成情報」タブの設定

### 基本情報枠

| 設定項目 | 説明 |
|---|---|
| パラメータシート名 | 作成する名称（「メインメニュー」は使用不可）。 |
| 作成対象 | 「パラメータシート(ホスト/オペレーションあり)」「パラメータシート(オペレーションあり)」「データシート」から選択。データシート選択時は「入力用」のみ表示、パラメータシート選択時は「ホストグループ」「バンドル」チェックボックスと「入力用」「代入値自動登録用」「参照用」欄が表示される。 |
| 表示順序 | メニューグループ内の表示順序（昇順）。 |
| ホストグループ | 作成対象がホスト/オペレーションありの場合に表示。チェックすればホストグループ対応、未チェックならホスト単位のパラメータシートを作成。 |
| バンドル | 作成対象がパラメータシートの場合に表示。チェックすればバンドル対応のパラメータシートを作成。 |
| 最終更新日時／最終更新者 | 自動入力（Backyardによる更新レコードは除外した最新情報を表示）。 |

### 対象メニューグループ枠

作成に使うメニューグループを選択します。デフォルトは「入力用」「代入値自動登録用」（データシートでは非表示）「参照用」（同）で、決定するとそのグループにメニューが作成されます。デフォルト以外を使う場合は事前に管理コンソールでメニューグループを作成しておく必要があります。「入力用」は選択必須です。

### 一意制約(複数項目)枠

データ登録時に複数項目の組み合わせで重複レコードを許さない制約を設定します。「パターンを追加」で組み合わせを複数設定可能。1パターンに項目が1つのみ、または同じ組み合わせのパターンが重複している場合はバリデーションエラーになります。

### アクセス許可ロール枠

ロールを選択した場合、パラメータシート定義（作成機能配下の各メニュー）と作成したメニューは選択ロールのみアクセス可能になります（メニュー側は「ロール/メニュー紐付管理」の設定に従う）。ロールを一つも選択しない場合、定義メニューは全ロールがアクセス可能、作成したメニューはシステム管理者ロールと作成ユーザーが所属するロールのみアクセス可能になります。

### プレビュー・作成

「プレビュー」タブで入力中の項目をテーブル形式で確認できます。「作成」ボタン押下で作成を実行し、「パラメータシート作成履歴」メニューで結果を確認します。作成すると「パラメータシート定義一覧」「カラムグループ管理」「パラメータシート項目作成情報」「一意制約(複数項目)作成情報」「パラメータシートロール作成情報」の各メニューに自動でデータが登録されます。

## 作成後の操作（編集・初期化・流用新規）

新規作成後は閲覧画面に遷移し、そこでは編集・作成はできません。Backyard処理完了前は「作成(新規)」ボタン、完了後は「作成(編集)」ボタンが表示されます（完了状況はパラメータシート作成履歴で確認可能）。

- **編集**: 入力用メニューグループのデータを保持したまま項目の追加・削除が可能。既存項目は「項目名」「正規表現」「説明」「備考」を自由に変更できますが、「最大バイト数」「最小値」「最大値」「桁数」「ファイル最大バイト数」は元の値より大きい値にのみ変更可能。正規表現変更後に既存データが不整合になっても保持されます。既存項目削除でそのデータは削除、新規項目追加はレコード空の状態で追加されます（必須/一意制約チェックでも空のまま登録され不整合が生じる場合あり）。対象メニューグループ変更時は変更前のメニューが廃止され変更後に新規登録（データは保持）。「パラメータシート名」「作成対象」「ホストグループ利用」「バンドル利用」は変更不可。既存項目名の交換はできず、項目名変更時にエラーが発生する可能性があります。
- **初期化**: 表示中のパラメータシートを再作成しますが、入力用メニューグループのデータはすべて削除されます。「パラメータシート名」以外は変更に制限がありません。
- **流用新規**: 表示中のパラメータシートをテンプレートとして新規作成する画面に遷移します。パラメータシート名は既存と異なる名前が必要です。

## パラメータシート定義一覧

作成したパラメータシートの一覧表示とメンテナンス（参照/更新/廃止/復活）を行います。主な項目: パラメータシート名(ja/en/rest)（作成済み後は変更不可）、シートタイプ（作成対象、プルダウン）、表示順序、バンドル／ホストグループ（該当する作成対象の場合Trueに設定可）、入力用／代入値自動登録用／参照用メニューグループ（プルダウンで選択）、パラメータシート作成状態（作成済み／未作成。作成済みだと名称変更不可）、説明(ja/en)、備考。**パラメータシート定義一覧でレコードを廃止しても、既に作成済みのメニュー（管理コンソール→メニュー一覧に表示されるもの）自体には変更が発生しません**（作成済みパラメータシートの廃止は別途手順が必要、後述）。

## パラメータシート作成履歴

Backyardがステータス「未実行」のデータを監視し、設定ファイル作成・テーブル作成（SQL実行）・画面プログラム配置と登録を行います。ステータスが「完了」になるとメニューグループに追加されます（数十秒程度）。項目: パラメータシート名、ステータス（未実行／実行中／完了／完了（異常））、作成タイプ（新規作成／初期化／編集）、備考。

## 作成されるパラメータシートの構造

### データシート（入力用のみ）

メンテナンス可能で、ホスト/オペレーションに紐づかないためそれらの項目は表示されません。項目: パラメータ（作成した項目）、備考。「代入値自動登録用」「参照用」は作成されません。

### パラメータシート（ホスト/オペレーションあり）

- **入力用**: ホスト名（機器一覧から選択）、オペレーション（オペレーション名選択、基準日時／実施予定日／最終実行日時は自動入力）、パラメータ（作成項目）、備考。ホスト・オペレーション単位でメンテナンス可能。
- **代入値自動登録用**: 閲覧専用。入力用の登録内容が一覧表示される。
- **参照用**: 閲覧専用。表示フィルタの「オペレーション：基準日時」で指定した時点の有効設定を一覧表示（未指定時はホスト名単位で基準日時が最新のデータのみ表示）。

### パラメータシート（オペレーションあり）

入力用の項目からホスト名が除かれ、オペレーション単位でメンテナンスします（他はホスト/オペレーションありと同様。参照用の未指定時表示は基準日時が最新のデータのみ）。

### パラメータシート（バンドル利用）

入力用では、登録済みの「ホスト名」と「オペレーション」（オペレーションありの場合はオペレーションのみ）の組み合わせに対し「代入順序」欄を追加入力することで複数のパラメータ値を設定できます（同じ組み合わせに複数値を持たせられる。バンドルを使わない場合は同一組み合わせへの重複登録はエラーとなり、項目を増やす方法では上限が固定され視認性も悪化するため、繰り返し設定にはバンドル利用が推奨されます。データシートにバンドルは利用不可）。項目: ホスト名（オペレーションありの場合は非表示）、オペレーション、代入順序、パラメータ、備考。代入値自動登録用・参照用は他パターンと同様。

### パラメータシート（ホストグループ利用）

入力用では、ホスト名項目にホスト名（先頭`[H]`）とホストグループ名（先頭`[HG]`）の両方をリスト選択できます。代入値自動登録用ではホストグループ機能によりホスト単位に分割されたデータを確認できます。参照用でも同様にホスト単位のデータが確認できます。

## 非表示メニューの設定内容

### カラムグループ管理

パラメータシートの項目見出しをまとめるカラムグループを管理します。項目: 親カラムグループ名（プルダウン）、カラムグループ名(ja/en)（`/` `\` 禁止）、フルカラムグループ名(ja/en)（親グループ名とグループ名を`/`で連結表示）、備考。更新・廃止時のチェック: 自身を親に指定不可、他の親に指定されている場合は廃止不可、ループする親子関係（A→B→CでCをAの親にする等）は設定不可。

### パラメータシート項目作成情報

パラメータシート/データシートの各項目を管理します。項目: パラメータシート名（プルダウン）、項目名(ja/en)（`/` `\` 禁止）、項目名(rest)（半角英数字と`_-`のみ）、説明(ja/en)、カラムグループ、カラムクラス（`SingleTextColumn`=文字列単一行、`MultiTextColumn`=複数行、`NumColumn`=整数、`FloatColumn`=小数、`DateTimeColumn`/`DateColumn`=カレンダー、`IDColumn`=プルダウン（参照項目で横並び表示可）、`PasswordColumn`=マスク表示、`FileUploadColumn`=ファイルアップロード、`HostInsideLinkTextColumn`=リンク表示、`ParameterSheetReference`=パラメータシート参照）、表示順序（昇順）、必須（True選択）、一意制約（True選択）、備考。

### 一意制約(複数項目)作成情報

パラメータシート名（プルダウン）と、一意制約を適用する項目名(rest)の組み合わせをリスト形式で指定します（例: `[["item_1", "item_2"], ["item_3", "item_4"]]`）。

### パラメータシートロール作成情報

パラメータシート名（プルダウン）と紐付けるロール（プルダウン）を設定します。

## 付録: パラメータシート定義-テーブル紐付管理・他メニュー連携（Backyard専用）

作成したパラメータシートとDBテーブル・他メニューとの紐付情報を表示する内部メニューです（ユーザー操作対象外。パラメータシート作成後に紐付を直接変更しても本メニューは追随しません）。「パラメータシート定義-テーブル紐付管理」の項目: パラメータシート名(・rest)、テーブル名、主キー、テーブル名（履歴）、備考。「他メニュー連携」の項目: メニューグループ名、メニュー名(・rest)、項目名(ja/en)、メニューグループ名:メニュー名:項目名(ja/en)、ID連携テーブル・PK・項目名(・rest)・ソート条件・多言語対応有無、カラムクラス、パラメータシート作成対象フラグ、備考。

## 付録: 選択1・選択2・参照項目情報（Backyard専用）

「選択1」は1択用のプルダウン項目（`*`）、「選択2」は2択用のプルダウン項目（`Yes-No`、`True-False`）を管理します。「参照項目情報」は「プルダウン選択」利用時の参照項目情報（他メニュー連携のID、メニューグループ名、メニュー名、表示順序、カラムクラス、項目名(ja/en/rest)、カラムグループ、ID連携テーブル・PK・項目名(・REST)・ソート条件・多言語対応有無、Sensitive設定、パラメータシート作成対象フラグ、説明(ja/en)、備考）を表示します。

## 付録: 「プルダウン選択」の「選択項目」で利用できる対象

| メニューグループ | メニュー | 項目 |
|---|---|---|
| 管理コンソール | メニュー管理 | メニューグループ名称+メニュー名称 |
| 基本コンソール | オペレーション一覧 / Movement一覧 | オペレーション名 / Movement名 |
| Ansible共通 | 機器一覧 / ファイル管理 / テンプレート管理 | ホスト名 / ファイル埋込変数名 / テンプレート埋込変数名 |

## 付録: 「プルダウン選択」の「参照項目」

プルダウン選択で選んだ値を基に、同じメニュー内の他項目を横並び表示させる機能です。「参照項目を選択」ボタンで対象項目にチェックし決定すると設定されます。代表的な参照項目対象: 管理コンソール:メニュー管理:メニュー名称→メニュー名(rest)、Ansible共通:機器一覧:ホスト名→DNSホスト名/IPアドレス/ユーザー/パスワード。加えて、選択項目がパラメータシート作成機能で作成したメニューの場合、そのパラメータシートの他項目でカラムクラスが「文字列(単一行/複数行)」「整数」「小数」「日時」「日付」「パスワード」「ファイルアップロード」「リンク」のいずれかであるものも対象です。参照項目を設定すると、入力用メニューグループの「登録」画面ではプルダウン項目のみ表示されますが、「一覧/更新」・代入値自動登録用・参照用の一覧では選択値と同じ行の値が横並びで表示されます。代入値自動登録用に表示される参照項目は、代入値自動登録設定で通常の値と同様に利用できます。

## 付録: 作成されたパラメータシートの廃止(論理削除)/復活

廃止したいパラメータシートは、管理コンソールのメニュー管理でメニュー名(ja/en/rest)を検索して対象を特定し（対象は、パラメータシート作成時に指定した対象メニューグループに属するメニュー）、廃止・復活を行います。廃止したパラメータシートは利用できなくなるため注意が必要です。廃止したパラメータシートをプルダウン項目・参照用項目・各ドライバの代入値自動登録で利用している場合、「ID変換失敗(X)」となります。同様に、廃止したパラメータシートのメニュー名・項目名を参照している他メニューの項目も同じ挙動になります。
