# 基本コンソールの設定と利用方法

基本コンソールは、ITAを利用して作業を行う上で共通に必要な機能を提供します。

## メニュー構成

| メニューグループ | メニュー画面 | 説明 |
|---|---|---|
| ITA基本コンソール | オペレーション一覧 | 投入オペレーション一覧をメンテナンス（閲覧/登録/更新/廃止）できます。 |
| ITA基本コンソール | Movement一覧 | 登録したMovementの一覧を閲覧できます（参照のみ）。 |

## オペレーション一覧

オーケストレータで実行する、作業対象ホストに対するオペレーション（例: 「サービス追加工事作業」）を管理します。

| 項目 | 説明 | 入力必須 | 制約事項 |
|---|---|---|---|
| オペレーションID | 自動入力される一意のID | - | - |
| オペレーション名 | 任意のオペレーション名 | 〇 | 最大256バイト |
| 実施予定日時 | オペレーションの実施予定日時。指定日時に実際の処理が実行されるわけではない。この日時が設定されたオペレーションに紐づく作業履歴は、指定の保存期間を過ぎると自動削除される。Conductor実行や各ドライバの作業実行でこのオペレーションを選択・実行した実績日時が表示される | 〇 | - |
| 最終実行日時 | 直近の実行日時（表示のみ、未実行なら空白） | - | - |
| 環境 | ワークスペース作成時に登録した環境が自動入力される（Exastro OASEやExastro EPOCHとの連携で使用） | - | - |
| 備考 | 自由記述 | - | - |

## Movement一覧

オーケストレータ利用時のMovementとオーケストレータの関連付けを参照のみで確認できます。Movementの実際の登録は、各Driverの利用手順マニュアルに従い各オーケストレータのITA用ドライバーのコンソールメニューから行います。
