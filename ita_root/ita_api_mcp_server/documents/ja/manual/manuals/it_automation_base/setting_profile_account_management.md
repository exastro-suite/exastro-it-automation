# アカウント管理

アカウント管理（ログインユーザーのアイコンメニューから選択）では、自身のアカウント編集、パスワード変更、二要素認証設定、トークン発行が行えます。Exastro IT Automation利用中はこのメニューは表示されません。

- **アカウント編集**: Eメール、名、姓、所属、説明を変更できます。ユーザー名は変更できません。
- **パスワード変更**: [Account security] > [Signing in] > [Basic authentication]から自身のパスワードを変更できます。
- **二要素認証設定**: [Account security] > [Signing in] > [Two-factor authentication]から、認証アプリを使った二段階認証を設定できます。
